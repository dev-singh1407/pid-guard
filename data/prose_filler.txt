# Why this file exists. The first version of the dilution study built its
# benign filler by concatenating benign *user requests* ("Write a Python
# function that...", "Sort the customer list by..."). Fifty of those in a row
# is not a benign document -- it is a stack of imperatives, which is
# structurally what an injection looks like: high imperative density, second
# person, obligation language. The control arm was therefore adversarial
# against our own structural detector and the measured false-positive rate was
# an artefact of the experiment, not a property of the system.
#
# These are descriptive document sentences instead: support articles, release
# notes, policy text, product documentation, reporting. Lines beginning with #
# are ignored.
